Why Doda Toolkit

What Makes It Different

100% Local

Every utility runs entirely in your browser. No data is ever sent to any server. Your privacy is built in.

Cross-Platform

Electron desktop app for Linux, Windows, and macOS. Also works in any browser via dev mode. Same experience everywhere.

Fast & Lightweight

Lazy-loaded code splitting — each utility loads only when you click it. Zero unnecessary downloads.

Beautiful UI

Glassmorphism design with gradient accents, smooth animations, dark/light/system theme. Emoji icons — zero bundle cost.

Keyboard-First

⌘K search palette with keyboard navigation, collapsible sidebar, favorites, recents, and press ? for the full shortcut reference.

Open Source

Fully open source on GitHub. MIT licensed. Built with React, TypeScript, Tailwind, and Electron.
